Put your audio files in this folder:

  voice-letter.m4a   <- your recorded voice message (already added) (.mp3 also works;
                        if you use .mp3, change voiceFile in index.html to match)
  someday.mp3        <- the song (already added)
                        CONFIG.song.youtubeId in index.html instead)

The file names must match what's written in the CONFIG section at the top of
the <script> in index.html.
